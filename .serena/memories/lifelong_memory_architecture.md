# Lifelong memory — архитектурная рамка (согласована 2026-07-03)

Расширение памяти от диалога к «памяти жизни». Реализация пилота: `mem:memory_measurements`. Устройство текущей памяти: `mem:modules/memory`.

## Инварианты рамки

- **Знать ≠ помнить.** Три судьбы входящего потока: live-state (НЕ хранится — источник истины снаружи, опрос MCP-тулой в момент вопроса; копия = проигранная гонка инвалидации), телеметрия (ряд `core.measurements`, в notes только агрегат/веха), память (notes/entities — ценное во времени).
- **Судьбу определяет источник, не LLM-классификатор.** Политика декларативная при подключении источника; Observer (LLM-extraction) — только на нарративных входах. Числа идут в ряд мимо LLM (контроль стоимости).
- **Storage-проблемы нет.** Жизнь одного человека — сотни МБ/год; PG+pgvector тянет десятилетия. Реальные ограничения: точность recall + стоимость extraction. Не тащить TimescaleDB/Neo4j.
- **Домен (работа/тело/быт) — не структура хранения.** Хранилище по форме данных; кластеры эмерджентны (плотные регионы вокруг сущностей), вычисляются на чтении.
- **Формы данных закрыты существующим:** событие = Note(observation, event_time); состояние = supersede/contradict-цепочка Reconciler; время = time-ветка recall; ряды = measurements. Проектировать от классов вопросов, не от данных.
- **Typed edges entity↔entity — отложены до боли** (recall стабильно промахивается на multi-hop, где co-mention `note_entities` + entity_cards не дотягиваются). Не строить онтологию отношений заранее.

## Live-слой (не реализован)

Push vs pull в контекст: push (ambient-блок в init, рядом с environment) — «часто релевантно + дёшево + агент сам не догадался бы спросить» (время, локация); pull (MCP-тула) — остальное (холодильник, приборы). Ambient мал и стабилен (3–5 строк). TTL-кэш — только при доказанно дорогом опросе.

## Принятые риски пилота

Семантические дубли метрик («вес»/«weight») — канонизация только форматная, разруливать sleep-дедупом по реальной картине. Приватность extraction: решено не решать (облачная LLM ок). Live-смок Telegram не проводился.

Очередь работ: `mem:backlog`.
